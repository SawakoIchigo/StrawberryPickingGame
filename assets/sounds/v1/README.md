# 効果音の試聴候補

[試聴ページ](index.html)で各候補を再生できます。ゲームにはまだ組み込んでいません。

| 場面 | A | B |
| --- | --- | --- |
| 収穫 | まるいしずく：ふっくらした短い水滴音（0.18秒） | 木の実はじける：軽く明るい弦を弾く音（0.22秒） |
| パック満杯 | みっつのベル：等間隔で上がる3音（0.64秒） | きらめく合図：リズムに変化のある澄んだ3音（0.64秒） |
| 出荷 | おとどけファンファーレ：上昇する4音と余韻（1.16秒） | あたたかなごほうび：柔らかな和音に重なる音の粒（1.22秒） |

全6本は44,100 Hz / 16-bit PCM / モノラルWAV。Cメジャーを基調としたオリジナルの合成音です。人声・録音素材・外部サービス・外部ライブラリは使用していません。ピークは0.68以下、冒頭と末尾は0にしています。短い音のため聴こえ方は再生機器でも変わります。

リポジトリルートで `python scripts/generate-sound-samples.py` を実行すると、Python 3.11標準ライブラリだけで同じWAVを再生成します。生成関数 `main()` の返値には長さ・ピーク・RMS・クレスト・DC成分・端点の診断値が含まれます。各候補のWAVは試聴ページから保存できます。
