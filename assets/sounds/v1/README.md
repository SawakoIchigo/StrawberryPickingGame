# 効果音の試聴候補

[試聴ページ](index.html)で各候補を再生できます。収穫の「まるいしずく」と満杯の「きらめく合図」は採用済み。出荷は画面の紙吹雪に合わせたクラッカーの新2案を選択中です。ゲームにはまだ組み込んでいません。

| 場面 | A | B |
| --- | --- | --- |
| 収穫 | **採用：まるいしずく**：ふっくらした短い水滴音（0.18秒） | 木の実はじける：軽く明るい弦を弾く音（0.22秒） |
| パック満杯 | みっつのベル：等間隔で上がる3音（0.64秒） | **採用：きらめく合図**：リズムに変化のある澄んだ3音（0.64秒） |
| 出荷・新案 | ぱっとクラッカー：1発の弾ける音と紙吹雪のさらさら（0.94秒） | お祝いダブルクラッカー：61ms差の2発、紙吹雪と控えめなチャイム（1.34秒） |

新出荷音は `ship-popper-a.wav` / `ship-popper-b.wav`。開始直後の短い帯域制限ノイズと丸い低中音でクラッカーを表現し、細かく減衰するノイズの粒で紙吹雪を添えています。ノイズは固定seedで再現します。人の擬音声は使っていません。

旧出荷4案 `ship-a.wav`（1.16秒）/ `ship-b.wav`（1.22秒）/ `ship-finale-a.wav`（1.98秒）/ `ship-finale-b.wav`（2.16秒）も比較用に残しています。採用2音を含む元8音は変更していません。

全10本は44,100 Hz / 16-bit PCM / モノラルWAV。音程のある部分はCメジャーを基調としたオリジナルの合成音です。人声・録音素材・外部サービス・外部ライブラリは使用していません。ピークは0.68以下、冒頭と末尾は0にしています。短い音のため聴こえ方は再生機器でも変わります。

リポジトリルートで `python scripts/generate-sound-samples.py` を実行すると、Python 3.11標準ライブラリだけで同じWAVを再生成します。生成関数 `main()` の返値には長さ・ピーク・RMS・クレスト・DC成分・端点の診断値が含まれます。各候補のWAVは試聴ページから保存できます。
