# 効果音の試聴候補

[試聴ページ](index.html)で各候補を再生できます。収穫の「まるいしずく」と満杯の「きらめく合図」は採用済み。出荷は合成した「お祝いの拍手」1案を試聴できます。ゲームにはまだ組み込んでいません。すべての音は外部の音源・録音・サンプルを使わず、コードから波形を合成しています。

| 場面 | A | B |
| --- | --- | --- |
| 収穫 | **採用：まるいしずく**：ふっくらした短い水滴音（0.18秒） | 木の実はじける：軽く明るい弦を弾く音（0.22秒） |
| パック満杯 | みっつのベル：等間隔で上がる3音（0.64秒） | **採用：きらめく合図**：リズムに変化のある澄んだ3音（0.64秒） |
| 出荷・新案 | お祝いの拍手：8人分の揺らぎを重ねた、声や歓声なしの合成拍手（2.55秒） | — |

新出荷音 `ship-applause.wav` は44,100 Hz / 16-bit PCM / stereo / 2.55秒。固定seedの乱数ノイズに帯域フィルタと滑らかな減衰を加え、手のひらと指が触れる音を合成します。8人分の独立したテンポ・タイミング・音色・左右位置を重ね、短い部屋の反射と穏やかな立ち上がり・終わりを加えています。声や歓声は含みません。

旧出荷6案 `ship-a.wav`（1.16秒）/ `ship-b.wav`（1.22秒）/ `ship-finale-a.wav`（1.98秒）/ `ship-finale-b.wav`（2.16秒）/ `ship-popper-a.wav`（0.94秒）/ `ship-popper-b.wav`（1.34秒）も比較用に残しています。採用2音を含む元10音は変更していません。

従来の10本は44,100 Hz / 16-bit PCM / モノラルWAVの合成音です。新しい拍手を含む全11本はピーク0.68以下、冒頭と末尾は0にしています。短い音のため聴こえ方は再生機器でも変わります。

リポジトリルートで `python scripts/generate-sound-samples.py` を実行すると、Python 3.11標準ライブラリだけで同じWAVを再生成します。生成関数 `main()` の返値には長さ・ピーク・RMS・クレスト・DC成分・端点の診断値が含まれます。各候補のWAVは試聴ページから保存できます。

拍手は `python scripts/generate-applause.py` でゼロから再生成します。こちらもPython標準ライブラリだけで動作し、入力音源・外部依存・ネットワーク接続は不要です。
