# 現在のゲーム用音源

この12本のMP3はユーザー提供ファイルです。ファイル名・内容を変更せず使用しています。

| ファイル | 使用場面 |
| --- | --- |
| `苺収穫_ランダム用001.mp3`〜`苺収穫_ランダム用004.mp3` | 収穫成功。4種すべてを1巡してから再シャッフル |
| `苺出荷可能.mp3` | パックが8個になった瞬間 |
| `クラッカー_ランダム用001.mp3`・`クラッカー_ランダム用002.mp3` | 出荷成功。2種を1巡してから再シャッフル |
| `苺腐った時.mp3` | 腐敗。同一更新の複数個はまとめて1回、最後の腐敗は終了音を優先 |
| `ゲーム開始.mp3` | 新しいゲームを開始したとき。休憩からの再開では鳴らさない |
| `ゲーム終了.mp3` | 終了に移ったときに1回 |
| `BGM_農場.mp3` | ゲーム中ずっとループ。雨が降っても継続 |
| `BGM_雨が降る.mp3` | 雨の間だけ農場BGMに重ねてループ。開始・終了は約0.8秒でフェード |

効果音55% / BGM25%で再生し、ゲーム内の音量設定UIは表示しません。BGM音量は農場・雨の2曲に共通です。雨の開始・終了だけをフェードし、休憩や終了では両方即時停止します。音源は初回の読み込み・デコード結果を再利用し、BGMは最大2本をブラウザー内でループします。音の実装はルートの `audio.js` にあります。v1は旧試作品として保持していますが、ゲームでは使用していません。
