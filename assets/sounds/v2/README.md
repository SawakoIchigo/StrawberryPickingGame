# 現在のゲーム用音源

この11本のMP3はユーザー提供ファイルです。ファイル名・内容を変更せず使用しています。

| ファイル | 使用場面 |
| --- | --- |
| `苺収穫_ランダム用001.mp3`〜`苺収穫_ランダム用004.mp3` | 収穫成功。4種すべてを1巡してから再シャッフル |
| `苺出荷可能.mp3` | パックが8個になった瞬間 |
| `クラッカー_ランダム用001.mp3`・`クラッカー_ランダム用002.mp3` | 出荷成功。2種を1巡してから再シャッフル |
| `苺腐った時.mp3` | 腐敗。同一更新の複数個はまとめて1回、最後の腐敗は終了音を優先 |
| `ゲーム開始.mp3` | 新しいゲームを開始したとき。休憩からの再開では鳴らさない |
| `ゲーム終了.mp3` | 終了に移ったときに1回 |
| `BGM_雨が降る.mp3` | 雨の間だけループ。休憩・終了・晴れで停止 |

効果音とBGMはゲーム内の「音」から個別調整できます。初期値55% / 25%、0%で消音。音の実装はルートの `audio.js` にあります。v1は旧試作品として保持していますが、ゲームでは使用していません。
