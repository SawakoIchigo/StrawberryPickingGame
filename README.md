# さわこいちごゲーム

イベントで子どもが遊ぶ、HTML / CSS / JavaScript の軽量な収穫ゲームです。苗が増えるにつれて、収穫とパックの出荷が忙しくなります。サーバー処理や外部ライブラリは不要です。

## 遊び方

1. 「あそぶ」で農場の時間が動きます。
2. **薄ピンク・赤・濃赤**のイチゴをタップ／クリックすると、画面上のパックに入ります。
3. **8個ちょうど**入ったら「おとどけする！」で出荷します。パックが満杯の間は、次のイチゴを入れられません。
4. 収穫せずに待つとイチゴは腐り、その後消えます。空いた場所にはまたつぼみができます。
5. ライフは **ハート10こ**で開始します。実が1個腐るごとに1つ減り、パック右側のハートが灰色になります。10こなくなるとゲーム終了です。「もういっかい あそぶ」で新しいゲームをすぐ始められます。

時間制限はありません。「ひとやすみ」で一時停止し、確認付きの「はじめから」で次の人に交代できます。「あそびかた」を開いている間も時間が止まります。別のタブやアプリへ移ると自動で一時停止します。ゲーム終了後は成長・収穫・出荷が止まり、最初から遊ぶとライフと収穫のきろくがリセットされます。

終了画面は約0.85秒かけて穏やかに表示し、このブラウザーに保存した得点の上位5件を並べます。今回の得点が0点を超え、過去の最高得点を上回ったときだけ「しんきろく！！」を表示します。負点・0点・同点・下位へのランクインでは表示しません。負の得点もそのまま記録し、同点は別プレイとして空き順位に入ります。同点で5位より後になる場合は更新しません。記録は再プレイ・再読み込み後も残り、保存機能が使えない場合はその画面を開いている間だけ記録を保持します。

収穫すると赤・ピンクの二重リングと、苺・葉・金色の粒が収穫地点から弾けます。パックへ移動する演出はありません。演出は操作を遮らず、短時間で消え、やり直し時にも消去します。端末のモーション軽減設定に関係なく、収穫演出と終了画面のフェードを表示します。

スマートフォンもPCも、畑とパックのエリアを縦に並べます。タイトル・操作ボタン・ポイントは横1列に表示します。右上は見出しを省き、大きな「○○てん」だけを中央に表示します。出荷数は表示しません。「いちごのおみせ」の見出しを省いて左側のパックを大きくし、右側にハート、「あと8こ」などを案内する出荷ボタン、画像付きの「いっしょに いちごを つもう！」を上から順にまとめています。PCでは画面の高さに収まる9:16のゲーム枠を中央に表示し、スマートフォンと同じ配置で操作できます。スマートフォンでは端末の画面の高さを使います。8個そろうと出荷ボタンが左右に大きく回転し、ピンク色の四角い波紋を出します。出荷すると、ゲーム画面の左右下隅から紙吹雪が勢いよく吹き上がります。左右それぞれ28〜40枚の粒を出し、方向・高さ・速度・回転・大きさ・形・色を毎回ランダムに変えます。演出中も操作できます。端末の「視差効果を減らす」設定に関係なく、実装した演出を有効にします。音・通信・外部ライブラリは追加していません。

## 成長ルール

### 苗

- 開始時は鉢の中央付近に **3段階の苗が1本**。
- 成長は全5段階。1→2、2→3、3→4、4→5 はそれぞれ基準15秒に **±2秒（13〜17秒）** のばらつきがあります。苗ごと・段階ごとに時間を決めます。
- 3・4・5段階でイチゴができます。
- 苗が5段階になった瞬間、周囲6か所の空き位置に1段階の新しい苗が1本生えます。周囲の出現順序はゲーム開始時にランダムで決め、そのゲーム中は固定します。
- 苗は最大 **7本**。新しい苗が増える時刻は、各苗の成長時間によって変わります。一時停止中は時間に含めません。

### イチゴ

つぼみ → 花 → 白イチゴ → 薄ピンク → 赤 → 濃赤 → 腐る → 消失

各イチゴの各状態について、基準時間に±2秒のばらつきを付けます。つぼみができた時に基準の成長予定を決め、表示更新や一時停止で再抽選しません。下表は雨による短縮前の時間です。

| 状態 | 次の状態まで | 収穫 |
| --- | ---: | --- |
| つぼみ | 2〜6秒（基準4秒） | 不可 |
| 花 | 2〜6秒（基準4秒） | 不可 |
| 白イチゴ | 3〜7秒（基準5秒） | 不可 |
| 薄ピンク | 3〜7秒（基準5秒） | 可 |
| 赤 | 5〜9秒（基準7秒） | 可 |
| 濃赤 | 3〜7秒（基準5秒） | 可 |
| 腐る | 2〜6秒で消失（基準4秒） | 不可 |

| 苗の段階 | 同時に育つイチゴの上限 | つぼみの発生間隔 |
| --- | ---: | ---: |
| 3 | 3個 | 6秒 |
| 4 | 5個 | 4秒 |
| 5 | 7個 | 2.5秒 |

つぼみの発生間隔は固定です。パックに詰めたイチゴは収穫時の状態を保ち、腐りません。収穫時に薄ピンクは50点、赤は150点、濃赤は50点を加算し、実が腐った時は1個につき500点とライフ1つを一度だけ減らします。出荷では得点を変えず、出荷したパック数を数えます。これらの調整値は `game-core.js` にまとめています。

### 雨

ゲーム内の時間で30〜60秒おきに雨が始まり、5〜10秒で晴れます。間隔は雨の開始から次の開始までです。休憩・あそびかたの表示中やゲーム終了後は、雨の時間も止まります。

雨の間は、**イチゴの各段階から次の段階へ移るまでの時間が、それぞれ1〜3秒短く**なります。つぼみ→花→白い実→薄ピンク→赤→濃赤→腐った実→消失の全7段階が対象で、赤以降の収穫できる時間や、腐ってから消えるまでの時間も短くなります。

雨が始まった時の現在の段階と、雨の間に新しく入る各段階に、一度ずつ短縮を適用します。雨の間に生まれたつぼみも対象です。短縮する秒数は雨ごとに決まり、一回の雨の間は同じです。残り時間が0.1秒より長い場合は最低0.1秒を残し、すでに0.1秒以下なら変更しません。晴れた後に新しく入る段階は通常の長さに戻りますが、すでに受けた短縮は取り消しません。苗の成長・つぼみの発生間隔は変わりません。

雨の間は畑に青いしずくと青灰色の雲が現れ、看板が「あめで すくすく！」に変わります。輪郭とハイライトのある半透明のしずくが最大48粒、斜めに落下し、落ち終わるたびに位置・速さ・間隔・大きさがランダムに変わります。雨の演出は降り始めと降り終わりの約1秒でなめらかにフェードイン・フェードアウトします。雨雲の色と濃さも雨粒と同じゲーム時刻に合わせてなめらかに変わり、モーション軽減設定でも急に切り替わりません。地面には小さな波紋が現れます。しずくは収穫操作を遮りません。端末設定に関係なく、48粒の落下と地面の波紋を表示します。一時停止中・ゲーム終了後は雨雲の変化とフェードを含む雨の演出も停止します。小さい画面では看板を省略し、畑とボタンの大きさを優先します。

実・花・つぼみには、組み込み imagegen で生成した `assets/game-sprites.png` を使っています。現在の苗の葉はSVGで描画します。生成プロンプトと検査結果は [画像の生成記録](docs/artwork.md) にあります。

風では根元と実を固定し、葉と葉柄だけが共通の穏やかな風に小さく追随します。一時停止中・ゲーム終了後は動きません。木製プランターの厚い縁・板の継ぎ目・木目と、暗い土の不規則な粒・陰影は、HTML内の静的SVGで描画します。

## ローカルで遊ぶ

このフォルダで以下を実行します。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで <http://127.0.0.1:8000> を開きます。終了はターミナルで `Ctrl+C`。Node.js や npm のインストールは、遊ぶためには不要です。

## 検証

Node.js 24 で、外部パッケージをインストールせずに実行できます。

```powershell
node --test
node --check game-core.js
node --check game.js
```

自動テスト55件、JavaScriptの構文検証、公開用ビルドが成功しています。ランキングの降順・上位5件・同点・負点・1ゲーム1回の保存と、壊れた保存データ・保存例外からの継続も自動テストで確認しています。生成されたHTML・JavaScript・CSS・素材の読み込みと、ブラウザー例外がないことも確認済みです。

Chromeのゲストモードの1ウィンドウで、PC・スマートフォンとレイアウトの切替境界を含む計21画面サイズを確認しました。PCの9:16枠と横1列のヘッダーを確認しています。拡大したパックの右側にハート・出荷ボタン・応援表示が収まり、パック面積は旧版比で50.3〜88.9%、各スロット面積は61.2〜99.9%増えました。ハートの減少・リセットと「0 / 8」の非表示も確認済みです。1366×768・1024×500・1024×400ではマウス、390×844ではタッチの計4画面サイズで、8粒の収穫・出荷・やり直しまで実操作し、数値の更新と狭い画面での出荷完了メッセージの収まりも確認しました。実行時例外は0件でした。

同じ21画面サイズでポイントの見出しがDOM・画面ともになく、999999てんが欠けず中央に表示されることを確認しました。数値は各表示幅で24／22／20／17pxから28／26／24／21pxへ、単位は9／9／8／7.5pxから11／11／10／9pxへ拡大しています。ヘッダーの横1列配置、出荷数の非表示、重なり・はみ出しがないことも確認済みです。

## GitHub Pages で公開

公開用ワークフローは `.github/workflows/pages.yml` です。ゲームと画像だけを公開用フォルダにまとめ、テストに成功した場合に公開します。

公開時はHTML・JavaScript・CSSの内容から共通の版を決め、JavaScriptの内部読み込み先も含めて版付きファイル名を参照します。更新前のJavaScriptと更新後のHTMLが混ざることを防ぎます。古いHTML向けの通常ファイル名も残しますが、すでに開いている画面には再読み込みが必要です。

Node.js 24で公開用ファイルをローカル生成・確認できます。

```powershell
node scripts/build-site.mjs
python -m http.server 8000 --bind 127.0.0.1 --directory _site
```

生成先の `_site/` はGit管理対象外です。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
2. ファイルを `main` ブランチに push するか、Actions の **Deploy strawberry game to Pages** を手動実行します。
3. 完了したワークフローの `github-pages` 環境に表示される URL で遊べます。

このリポジトリ名の標準公開先は `https://sawakoichigo.github.io/StrawberryPickingGame/` です。公開の実施・成功を示すものではありません。

公開設定の詳細は [GitHub 公式ドキュメント](https://docs.github.com/ja/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) を参照してください。

畑は六角形の木枠と土面に中央＋周囲の最大7株を配置します。ライフは10個のハートを5列×2段で表示し、こい赤の実は深い赤で見分けられます。

右上の点数は加点・減点1回につき0.5秒で遷移します。途中は10点単位で表示し、連続操作でも各変化がそれぞれ0.5秒で完了します。カウント中は数値と「てん」を少し拡大し、到達すると元の大きさへ戻ります。実際の得点・結果・ランキングは即時更新されます。端末設定に関係なく数字のカウントと拡大縮小を表示します。

Chromeゲストで端末のモーション軽減設定が有効な状態も含め、実際のタップ・クリックで薄ピンクと濃赤の実を収穫し、0→10→20→30→40→50と1.06倍→元のサイズへの復帰を確認しました。8個の実収穫による出荷ボタンのピンク色の四角い波紋、休憩・再開・出荷後の切り替え、連続収穫後の拡大解除、収穫と出荷の演出も確認しています。7株の出現順序は再開始で変わり、後から株が増えても既存株の位置は変わりません。

今回の調整はChromeゲストの1ウィンドウで、390×844・320×568・1440×900・1024×400の実操作を検証しました。加点50/150点と減点500点は約0.5秒で表示が完了し、元の文字サイズに戻ります。回転する出荷ボタンはハート・案内文に重ならず、波紋はピンクです。左右下からの紙吹雪は毎回数・形・色・軌道が変わり、終了後に消えます。収穫地点のリングは残し、パックへ飛ぶ実は削除しました。マイナスの結果では新記録を表示せず、正の最高点更新で表示することも確認しています。
