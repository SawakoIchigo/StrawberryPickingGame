# いちごつみゲーム

イベントで子どもが遊ぶ、HTML / CSS / JavaScript の軽量な収穫ゲームです。苗が増えるにつれて、収穫とパックの出荷が忙しくなります。サーバー処理や外部ライブラリは不要です。

## 遊び方

1. 「収穫をはじめる」で農場の時間が動きます。
2. **薄ピンク・赤・濃赤**のイチゴをタップ／クリックすると、画面上のパックに入ります。
3. **8個ちょうど**入ったら出荷します。パックが満杯の間は、次のイチゴを入れられません。
4. 収穫せずに待つとイチゴは腐り、その後消えます。空いた場所にはまたつぼみができます。
5. ライフは **ハート3つ**で開始します。実が1個腐るごとに1つ減り、右上のハートが灰色になります。3つなくなるとゲーム終了です。「もう一度あそぶ」で最初から遊べます。

時間制限はありません。「ひとやすみ」で一時停止し、「やりなおす」で次の人に交代できます。別のタブやアプリへ移ると自動で一時停止します。ゲーム終了後は成長・収穫・出荷が止まり、最初から遊ぶとライフと収穫のきろくがリセットされます。

## 成長ルール

### 苗

- 開始時は鉢の中央付近に **3段階の苗が1本**。
- 成長は全5段階。1→2、2→3、3→4、4→5 はそれぞれ基準15秒に **±2秒（13〜17秒）** のばらつきがあります。苗ごと・段階ごとに時間を決めます。
- 3・4・5段階でイチゴができます。
- 苗が5段階になった瞬間、その苗の近くに1段階の新しい苗が1本生えます。
- 苗は最大 **5本**。新しい苗が増える時刻は、各苗の成長時間によって変わります。一時停止中は時間に含めません。

### イチゴ

つぼみ → 花 → 白イチゴ → 薄ピンク → 赤 → 濃赤 → 腐る → 消失

各イチゴの各状態について、基準時間に±2秒のばらつきを付けます。つぼみができた時に成長予定を決め、表示更新や一時停止で再抽選しません。

| 状態 | 次の状態まで | 収穫 |
| --- | ---: | --- |
| つぼみ | 2〜6秒（基準4秒） | 不可 |
| 花 | 2〜6秒（基準4秒） | 不可 |
| 白イチゴ | 3〜7秒（基準5秒） | 不可 |
| 薄ピンク | 3〜7秒（基準5秒） | 可 |
| 赤 | 5〜9秒（基準7秒） | 可 |
| 濃赤 | 3〜7秒（基準5秒） | 可 |
| 腐る | 2〜6秒で消失（基準4秒） | 不可 |

| 苗の段階 | 同時に育つイチゴの上限 | つぼみの発生間隔 |
| --- | ---: | ---: |
| 3 | 3個 | 6秒 |
| 4 | 5個 | 4秒 |
| 5 | 7個 | 2.5秒 |

つぼみの発生間隔は固定です。パックに詰めたイチゴは収穫時の状態を保ち、腐りません。収穫時に薄ピンクは50点、赤は150点、濃赤は50点を加算し、実が腐った時は1個につき50点とライフ1つを一度だけ減らします。出荷では得点を変えず、出荷したパック数を数えます。これらの調整値は `game-core.js` にまとめています。

実・花・つぼみには、組み込み imagegen で生成した `assets/game-sprites.png` を使っています。現在の苗の葉はSVGで描画します。生成プロンプトと検査結果は [画像の生成記録](docs/artwork.md) にあります。

## ローカルで遊ぶ

このフォルダで以下を実行します。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで <http://127.0.0.1:8000> を開きます。終了はターミナルで `Ctrl+C`。Node.js や npm のインストールは、遊ぶためには不要です。

## 検証

Node.js 24 で、外部パッケージをインストールせずに実行できます。

```powershell
node --test
node --check game-core.js
node --check game.js
```

自動テスト25件とJavaScriptの構文検証が成功しています。HTMLからのファイル参照、ローカル配信、PC上の縦9:16枠でのブラウザー表示・操作も確認済みです。

成長時間のランダム化と新しい風・配置は、320×568・390×844でブラウザー確認済みです。5本の苗と最大35個の実が枠内に収まり、操作領域の重複はありません。風による揺れ、実の配置の維持、一時停止・再開、実の位置からの加点表示、8個収穫後の満杯制限と出荷、やりなおしによる初期化を確認しています。

同じ画面サイズで、中央から始まる苗・大きくした葉・イチゴ中心の波紋・ライフの赤／灰色表示も確認済みです。3個目の腐敗でゲームが止まり、終了後の操作で進行せず、もう一度遊ぶとハート3つに戻ります。

対応ブラウザーでは、任意の WebMCP 機能からゲームの開始・状態取得・収穫・出荷を操作できます。非対応ブラウザーでも通常のゲームは動作します。WebMCP の対応実行環境での検証は未実施です。

## GitHub Pages で公開

公開用ワークフローは `.github/workflows/pages.yml` です。ゲームと画像だけを公開用フォルダにまとめ、テストに成功した場合に公開します。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
2. ファイルを `main` ブランチに push するか、Actions の **Deploy strawberry game to Pages** を手動実行します。
3. 完了したワークフローの `github-pages` 環境に表示される URL で遊べます。

このリポジトリ名の標準公開先は `https://sawakoichigo.github.io/StrawberryPickingGame/` です。公開の実施・成功を示すものではありません。

公開設定の詳細は [GitHub 公式ドキュメント](https://docs.github.com/ja/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) を参照してください。
